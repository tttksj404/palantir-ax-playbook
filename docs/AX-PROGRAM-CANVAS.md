# AX 전환 프로그램 캔버스

> 특정 유스케이스 하나가 아니라, 조직 전체의 AX 전환 방향·포트폴리오·기반·조직·성과를 합의하기 위한 작성 템플릿입니다.

이 문서는 [AX 전환 가이드](AX-TRANSFORMATION-GUIDE.md)의 실행판입니다. 빈칸을 채운 뒤 경영진·현업·기술·보안 담당자가 함께 검토합니다.

### North Star 문장

```text
우리 조직은 [대상 고객/직원/운영]이 [핵심 결과]를 얻도록
[업무·의사결정·제품]을 AI와 사람의 협업 방식으로 전환한다.
성공은 [결과 지표]의 변화로 판단하고, [금지 조건]은 허용하지 않는다.
```

### 원칙

- [ ] 업무 가치가 모델 선택보다 우선
- [ ] 사람의 책임·권리·안전을 보호
- [ ] 최소 권한과 목적에 필요한 데이터만 사용
- [ ] 읽기·추천·준비·실행 권한을 단계화
- [ ] 근거·평가·감사·중단을 제품 기능으로 취급
- [ ] 사용량이 아니라 실제 성과로 투자 판단

## 5. 우선순위 결정

### 점수 정의

```text
우선순위 = (가치 × 전략 적합성 × 반복성 × 데이터 준비도 × 채택 가능성)
           ÷ (위험도 × 통합 난이도 × 변화 부담)
```

점수만으로 결정하지 말고 아래를 함께 작성합니다.

| 질문 | 판단 |
|---|---|
| 이 업무를 지금 바꾸지 않으면 어떤 손실이 생기는가? |  |
| 가장 작은 안전한 파일럿 범위는 어디까지인가? |  |
| 실패를 감지하고 되돌릴 수 있는가? |  |
| 누가 매주 실제로 테스트할 것인가? |  |
| 다른 업무에 재사용할 기반은 무엇인가? |  |
| 실패했을 때 학습 가치가 남는가? |  |
